# rl_llm

A collection of tutorials and demos for reinforcement learning (RL) with large language models (LLMs).

## Contents

- Example scripts for training and playing with RL agents and LLMs
- Tic-Tac-Toe PPO demos
- Llama model learning scripts

## Libraries & Technologies Used

- [transformers (Hugging Face)](https://huggingface.co/docs/transformers) for LLMs (Llama, TinyLlama)
- [PyTorch](https://pytorch.org/) for deep learning
- [stable-baselines3](https://stable-baselines3.readthedocs.io/) and [sb3_contrib](https://sb3-contrib.readthedocs.io/) for RL algorithms (PPO, MaskablePPO)
- [PettingZoo](https://pettingzoo.farama.org/) for multi-agent RL environments (Tic-Tac-Toe, Connect Four)
- [Gymnasium](https://gymnasium.farama.org/) for RL environment interface
- [NumPy](https://numpy.org/) 

## Algorithms

- Proximal Policy Optimization (PPO)
- Maskable PPO (for environments with invalid action masking)

See the `tutorials/` directory for example scripts and usage.
